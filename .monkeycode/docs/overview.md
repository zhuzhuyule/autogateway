# 需求概述

## 项目背景

GPT-Load 是一个优秀的 Go + Vue3 开源代理项目，支持多上游 API 集成、负载均衡、自动容错等功能。但缺少以下能力：

1. **Auto 复杂度路由** — 根据请求复杂度自动选择合适模型
2. **统一模型目录** — 聚合所有分组模型，统一对外暴露
3. **模型自动去重** — 智能发现并建议聚合重复模型

本项目旨在为 GPT-Load 添加上述功能，同时保持与上游的兼容性。

## 功能详情

### 1. Auto 复杂度路由

根据请求特征自动将请求路由到合适的模型分组：

| 复杂度级别 | 判断条件 | 路由目标 |
|-----------|----------|----------|
| Simple | token < 2000, 无 tools, 无 vision | lite 分组 |
| Medium | token 2000-8000 或 有 tools 或 message > 10 | pro 分组 |
| Complex | token > 8000 或 有 vision 或 tools > 3 | max 分组 |

### 2. 统一模型目录

提供统一的 `/v1/models` API，聚合所有分组中的模型：

- 自动收集所有分组中的模型
- 按逻辑模型名去重合并
- 返回模型提供者列表
- 支持缓存

### 3. 模型自动去重

智能分析现有分组配置：

- 发现被多个分组提供的相同模型
- 提供聚合建议
- 支持一键创建聚合分组
